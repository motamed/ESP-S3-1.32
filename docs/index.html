Halo

A Home Assistant voice satellite with a 466×466 round touch dashboard. On-device wake word, local speech, and a screen that actually earns its place on your shelf.

Your browser can’t talk to serial devices. Use Chrome, Edge, or Opera on desktop. Web Serial needs a secure context — open this page over HTTPS.

Flashes over USB straight from this page. Nothing to install.

How it works

  1. Plug it in

    Connect the board to your computer with a USB-C data cable. Charge-only cables are the single most common reason the device never shows up.

  2. Install

    Hit Connect & install and pick the serial port. If no port appears, hold BOOT, tap RESET, then release BOOT to force the bootloader.

  3. Join Wi-Fi

    When the flash finishes, the page offers to send Wi-Fi credentials over the same cable via Improv. No hotspot juggling.

  4. Adopt in Home Assistant

    Home Assistant discovers it automatically. Click adopt, assign an Assist pipeline, then import the dashboard blueprint and pick your entities from dropdowns — no YAML, no reflashing.

What you get

On-device wake word

microWakeWord runs on the ESP32-S3 itself. Audio only leaves the device after you address it.

Round dashboard

Swipe between clock, lights, sensors, and media. Arc dimmers and dial thermostats built for a circular panel.

Real audio

ES8311 codec with onboard mic and a speaker header — TTS replies, timers, chimes, and announcements.

True-black idle

AMOLED means unlit pixels draw nothing. The idle face is designed around that instead of fighting it.

Set up without YAML

Pick your lights and sensors from dropdowns in Home Assistant. Nothing is compiled in, so you can change them anytime without reflashing.

OTA forever

You only need the cable once. Every later update ships over your network from Home Assistant.

Yours to change

Plain ESPHome YAML. Fork it, edit a page, and rebuild — no C++ required.

If something goes wrong

No serial port in the picker
Use a data-capable USB-C cable, then force the bootloader: hold BOOT, tap RESET, release BOOT. On Windows you may need the CH34x/CP210x driver.
The install button never appears
Web Serial is desktop-only and unsupported in Firefox and Safari. Chrome, Edge, or Opera will work.
Screen stays black after flashing
Give it about 30 seconds on first boot. If it stays dark, check the USB serial log — a mismatched flash or PSRAM mode shows up there as a boot loop.
The climate page just shows “--”
The screen is waiting for Home Assistant to send it values. Import the dashboard blueprint and pick your sensors — the page fills in within a few seconds.
It flashed, but Home Assistant can’t see it
Confirm it joined the right 2.4 GHz network — the ESP32-S3 has no 5 GHz radio. Then check Settings → Devices & Services for a discovered ESPHome device.
